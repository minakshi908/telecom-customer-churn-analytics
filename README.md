# Telecom Customer Churn Analytics & Executive Dashboard

An end-to-end data analytics project focused on identifying customer attrition drivers, quantifying revenue risk, and delivering actionable retention strategies for a telecom enterprise.

## 🚀 Project Workflow Overview
1. **Data Engineering (Python & VS Code):** Used Python and the Pandas library to audit raw operational data, handle missing values, and clean data types into an accurate schema (`clean_telecom_churn.csv`).
2. **Dashboard Architecture (Power BI):** Deployed the clean dataset into Power BI to construct an enterprise-grade executive dashboard focused on data layout grids, scannability, and key financial metric container logic.
3. **AI-Assisted Development:** Actively leveraged Generative AI as a technical co-pilot to accelerate Python script debugging, optimize nested visual layers in Power BI, and speed up project iteration cycles.

## 💡 Key Business Insights Discovered
* **Product Deficit Over Service:** The primary driver for customer loss is users migrating to competitors offering higher download speeds and superior data packages. Attrition is a product infrastructure issue rather than a service failure.
* **Contractual Risk:** Month-to-month contracts contain the vast majority of our overall revenue risk (\$31M CLTV at Risk).
* **Onboarding Friction:** The attrition timeline reveals a major drop-off in months 1-5, highlighting where targeted customer retention programs must be deployed.
